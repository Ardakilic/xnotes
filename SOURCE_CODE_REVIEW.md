# Source Code Review Notes (AMO / store review)

## How to build this extension from source

Requirements: Docker + GNU make. Nothing else (no host Node.js needed).

```sh
make setup   # install pinned dependencies inside a node:22-bookworm-slim container
make build   # produces .output/chrome-mv3/ and .output/firefox-mv3/
make zip     # produces store-ready zips in .output/, including the sources zip
```

The Firefox zip is `xnotes-<version>-firefox-mv3.zip`; the accompanying sources archive is generated by WXT automatically (`xnotes-<version>-sources.zip`).

## Build correspondence

- Build tool: [WXT](https://wxt.dev) (pinned exact version in `package.json`), Vite-based.
- `npm ci && npm run build:firefox` (equivalently `make build`) is the complete build; there are no manual post-processing steps.
- Entrypoints live in `entrypoints/`; shared logic in `src/`. No minification-obscured hand-written code — all output is Vite-bundled from the TypeScript sources in this archive.

## Verifying tests

```sh
make typecheck lint test integration
```

## Notes for reviewers

- The extension communicates only with x.com/twitter.com (content script) and a user-configured sync backend (optional). See `PRIVACY.md`.
- No remote code is loaded; no eval; content-security-policy-friendly DOM construction throughout.
